  <Decisions
    items={[
      { title: 'PostgreSQL decides who gets the court', why: 'Production uses an EXCLUDE constraint on the court and time range. It keeps working even if someone adds another route that inserts bookings tomorrow. Pessimistic and optimistic versions exist too, and pass the same tests.', rejected: 'checking only in the application, SERIALIZABLE for every transaction, and an in-memory mutex that cannot see other Vercel instances.' },
      { title: 'Opaque cookie sessions, not JWT', why: 'A random 32-byte token in an HttpOnly __Host- cookie, stored hashed. Logout and “sign out everywhere” revoke instantly. CSRF is covered by SameSite=Lax plus an Origin check.', rejected: 'JWT in localStorage, readable by any XSS, and JWT in a cookie, which still cannot be revoked before it expires.' },
      { title: 'One Zod contract, mappers at every border', why: 'The same schemas validate requests on the server and responses on the client. Changing a field touches three places, and nothing compiles until they agree.', rejected: 'hand-written types on each side that drift apart silently.' },
    ]}
  />
</Block>
